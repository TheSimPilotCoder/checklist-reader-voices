# Checklist Reader – neural voice files

This repository exists for one purpose: to hold a stable copy of the two files that
[Checklist Reader](https://flightsim.to/) downloads when a user enables its optional
neural voices. Nothing here is original work, and nothing here has been changed.

The files are served from the [releases](../../releases) of this repository so that the
application has an address that will not disappear, and so that no third party's
repository carries the download traffic of our users.

## What the files are

| File | Size | What it is |
|---|---|---|
| `kokoro-v1.0.int8.onnx` | 88 MB | the speech model, quantised to int8 |
| `voices-v1.0.bin` | 27 MB | the voice style vectors |

SHA-256, byte-for-byte identical to the upstream release:

```

bca610b8308e8d99f32e6fe4197e7ec01679264efed0cac9140fe9c29f1fbf7d  voices-v1.0.bin
```
