# Checklist Reader – speech model files

This repository exists for one purpose: to hold a stable copy of the model files that
[Checklist Reader](https://flightsim.to/) downloads when a user enables its optional
neural voices (Kokoro) or its optional Whisper speech recognition. Nothing here is
original work, and nothing here has been changed.

The files are served from the [releases](../../releases) of this repository so that the
application has an address that will not disappear, and so that no third party's
repository carries the download traffic of our users.

| Release | What it holds | Licence |
|---|---|---|
| [`model-files-v1.0`](../../releases/tag/model-files-v1.0) | Kokoro neural voices | Apache 2.0 – [LICENSE](LICENSE) |
| [`whisper-models-v1.0`](../../releases/tag/whisper-models-v1.0) | Whisper speech recognition | MIT – [LICENSE-WHISPER](LICENSE-WHISPER) |

### What the files are

| File | Size | What it is |
|---|---|---|
| `kokoro-v1.0.int8.onnx` | 88 MB | the speech model, quantised to int8 |
| `voices-v1.0.bin` | 27 MB | the voice style vectors |

```

### Where they come from

- The speech model is **Kokoro-82M** by **hexgrad**, licensed under the
  **Apache License, Version 2.0**: <https://huggingface.co/hexgrad/Kokoro-82M>
- The ONNX conversion and int8 quantisation were produced by the `kokoro-onnx`
  projects of **taylorchu** (<https://github.com/taylorchu/kokoro-onnx>) and
  **thewh1teagle** (<https://github.com/thewh1teagle/kokoro-onnx>), whose own
  conversion tooling is MIT-licensed. The model weights inside the files remain
  under the Apache License 2.0.
- The files in this repository were taken unaltered from
  <https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0>.
  The SHA-256 values above are the proof of that.

**No modifications have been made to the Work.** The files are reproduced here
exactly as published; only their hosting location differs.

## Whisper speech recognition

### What the files are

Three sizes of the same English speech recognition model; the user picks one inside
Checklist Reader, which runs it offline on the processor through whisper.cpp.

| File | Size | What it is |
|---|---|---|
| `ggml-base.en-q5_1.bin` | 57 MB | Whisper base.en, quantised to q5_1 (recommended) |
| `ggml-small.en-q5_1.bin` | 181 MB | Whisper small.en, quantised to q5_1 |
| `ggml-large-v3-turbo-q5_0.bin` | 547 MB | Whisper large-v3-turbo, quantised to q5_0 |

SHA-256, byte-for-byte identical to the upstream files:

```
4baf70dd0d7c4247ba2b81fafd9c01005ac77c2f9ef064e00dcf195d0e2fdd2f  ggml-base.en-q5_1.bin
bfdff4894dcb76bbf647d56263ea2a96645423f1669176f4844a1bf8e478ad30  ggml-small.en-q5_1.bin
394221709cd5ad1f40c46e6031ca61bce88931e6e088c188294c6d5a55ffa7e2  ggml-large-v3-turbo-q5_0.bin

### Where they come from

- The speech model is **Whisper** by **OpenAI**, licensed under the **MIT License**:
